# Размещение для просмотра на VPS

GitHub содержит исходники; работа сайта требует Python-сервера. Подготовленная конфигурация запускает приложение отдельным сервисом и примерно через сутки останавливает только его, не выключая VPS.

## Пакет

На компьютере разработчика:

```sh
scripts/pnpm.sh build
scripts/package-vps.sh
```

Архив `output/vps/phoenix-release.tar.gz` содержит backend, собранный frontend, шрифт PDF и фиксированные Python-зависимости. Он не содержит `.env`, API-ключ, Git, зависимости Node или диагностические ответы модели.

## Настройка сервера

Перед установкой проверить ОС, Python (3.11+), доступ к sudo, свободные порты и существующий reverse proxy. Не заменять конфигурацию других сайтов.

- Распаковать релиз в `/opt/phoenix-review/current`.
- Создать `/opt/phoenix-review/.venv` и установить зависимости из `current/requirements.lock.txt`.
- Хранить серверные переменные в `/etc/phoenix-review.env` с правами `0600`. Ключ передаётся отдельно по SSH и не включается в архив или GitHub.
- Установить systemd-файлы из этой папки. Приложение слушает только `127.0.0.1:18080`; внешний доступ направляет Nginx. Шаблон `nginx/phoenix-review.conf` рассчитан на текущий IP; перед повторным размещением нужно проверить адрес и свободный порт 80.
- В reverse proxy установить лимит тела запроса от 3 МБ и время ожидания ответа не менее 100 секунд, поскольку анализ с коррекцией ограничен 95 секундами.
- После проверки приложения запустить `phoenix-review-stop.timer`. Он отключит сервис через 24 часа после активации таймера. Перезагрузка с повторной активацией таймера начинает этот период заново.

Для эксплуатации HTTPS и адрес сайта настраиваются по фактическому домену и конфигурации VPS. Шаблоны не предполагают, что порты 80/443 свободны.

## Проверка

Проверить `/api/health`, интерфейс, три демопримера, цитаты и редактирование, выгрузку PDF/JSON/SVG/Markdown, один живой разбор учебного TXT и состояние таймера. `/api/health` подтверждает наличие конфигурации, но не доступность внешней модели.

Материалы пользователя и диагностические ответы не копируются из `output/` на VPS. Локальное рабочее состояние браузера не является постоянным хранилищем.

## Текущее временное размещение

Адрес: http://45.8.93.175. Ubuntu 24.04, Python 3.12, отдельный сервис `phoenix-review`; существующий сервис `fpshka` продолжает работу. Для текущего показа используется HTTP по IP. Ключ ChatCI хранится в закрытом серверном файле окружения.

Таймер текущего показа: остановка 26 ноября 2026 около 00:34 МСК (25 ноября 21:34 UTC), если VPS не перезагружается. Проверено: три демопримера, живой разбор (21 шаг, 4 потери, 3 рекомендации за 36,5 с), PDF на одну страницу. При повторном живом запросе модель вернула результат, отклонённый проверкой оснований: стабильность произвольных стенограмм требует дальнейшей диагностики.
